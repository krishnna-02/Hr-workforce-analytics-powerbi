# Hr-workforce-analytics-powerbi
Interactive HR Workforce Analytics dashboard built with Power BI, DAX &amp; Power Query to analyze workforce, attrition, hiring, compensation and training insights.
# 📊 HR Workforce Analytics Dashboard

> **An interactive Power BI dashboard for turning employee data into clear, actionable HR insights.**

This project is a **3-page HR Analytics Dashboard** built using **Microsoft Power BI, DAX and Power Query**.
It focuses on workforce composition, employee attrition, hiring trends, compensation and training investment.

---

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Data Modeling**
* **Data Visualization**

---

# 📌 Dashboard Overview

## 👥 1. Workforce Overview

The **Workforce Overview** page provides a high-level view of the organization's workforce.

### Key Analysis

* Active Workforce
* Company-Wide Headcount
* Average Salary
* Female Diversity %
* Bench Utilisation %
* Workforce Distribution by Department
* Workforce Mix by Career Level
* Performance Distribution by Department

# 🎯 Project Objective

The objective of this project is to demonstrate how **Power BI, DAX and Power Query** can transform employee data into an interactive analytical solution for understanding:

**Workforce → Attrition → Hiring → Compensation → Training**

The dashboard is designed to support **data-driven HR decision-making** through clear KPIs, interactive filters and business-focused visualizations.
